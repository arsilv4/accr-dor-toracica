# ACCR Dor Torácica: Simulação Clínica Virtual

Simulação clínica virtual em Acolhimento com Classificação de Risco (Sistema Manchester) de um adulto com dor torácica.

**Jogar:** https://arsilv4.github.io/accr-dor-toracica/

Use um navegador de computador (Chrome, Edge, Firefox ou Safari). Clique uma vez na página para liberar o som.

Material educacional. Avatares: Microsoft Rocketbox (MIT). Vozes: Piper TTS (faber, CC0; edresson, CC BY 4.0) e Kokoro TTS (Apache-2.0). Fonte: Inter (SIL OFL). Detalhes em `licencas/`.
